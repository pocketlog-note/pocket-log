# 記事の品質基準

関連: [[strategy]]

## 合言葉

**「教科書」じゃなくて「友達のLINE」。でも中身はちゃんと正しい。**

## 1. タイトル

- 32文字前後。スマホの検索結果で切れない長さ。
- 次のうち2つ以上を入れる: **具体的な数字**／**ベネフィット（読むと何が得か）**／**本音・意外性**
- NG: 「〜とは？〜の考え方」（教科書っぽい）、「〜のコツ」だけ（ふわっとしている）

| ダメな例 | 良い例 |
|---|---|
| 「ポケット消費」とは？ 小さな出費で満足度を上げる考え方 | 給料日前でも満たされる。月3,000円の「ご褒美枠」を作ったら散財が減った話 |
| 小さなご褒美を選ぶ3つのルール | 「買って後悔」がゼロになった、500円ご褒美の選び方3つ |

## 2. 書き出し（最初の3行で勝負）

- 読者の「あるある」から入る。「〜ですよね」「〜しがちじゃないですか？」
- 2〜3行目で「この記事で何が分かるか」を言い切る。
- 定義や背景説明から始めない（それは後半か、無くてよい）。

## 3. 本文

- **1段落は3行まで**。スマホで詰まって見えないように。
- **見出しは「答え」にする**。「ルール1」ではなく「ルール1：迷ったら翌朝まで待つ」。
- **体験を最低1つ入れる**。いつ・何を・いくらで・どうだったか。良かった点だけでなく、微妙だった点も。
- **数字は具体的に、出典付きで**。価格は「2026年11月時点・〇〇調べ」と書く。
- 太字は1見出しにつき1〜2か所まで（多いと逆に目立たない）。
- 「〜と言えるでしょう」「〜が重要です」「いかがでしたか」は使わない（AIっぽく見える定型句）。

## 4. 締め

- 「明日できること」を1つだけ提案して終わる。
- 関連記事へのリンクを1〜2本。

## 5. 公開前チェックリスト

- [ ] タイトルに数字かベネフィットが入っている
- [ ] 最初の3行で、何が得られるかが分かる
- [ ] 体験（実際にやった・買った）が1つ以上ある。**捏造していない**
- [ ] 価格・数値・商品名に出典か調べた日付がある
- [ ] アフィリエイトリンクがあれば、冒頭にPR表記がある
- [ ] 身元に繋がる情報が入っていない
- [ ] スマホで読んで、詰まって見える段落がない
- [ ] 声に出して読んで、堅すぎる・不自然な文がない
- 全部OKなら `draft: true` を消して公開

## 6. 記事の型（どれかに当てはめる）

| 型 | 例 | 役割 |
|---|---|---|
| やってみた | 1週間、ご褒美を500円に絞ってみた | 信頼・ファン作り |
| 選び方・比較 | 1000円以下で買える〇〇、3つ試して比べた | 収益（商品リンク） |
| あるある解決 | 給料日前に散財しない仕組み | 検索流入 |
| 旬ネタ | 今年の流行語「〇〇」、家計目線でどう？ | SNS拡散 |
