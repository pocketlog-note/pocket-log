# ポケットログ 戦略メモ

最終更新: 2026-11-21 ／ 関連: [[article-guide]]

## 1. 目指す姿（一言で）

**「1000円以下で、今日がちょっと良くなる」を本気で試して、正直に書く匿名メディア。**

- 読者: 物価高で大きな買い物は控えたいが、小さな楽しみは手放したくない20〜40代。スマホで、通勤中や寝る前に読む。
- 読後感: 「これ買ってみよ」「自分もやってみよ」と思える。読み終わって行動できる。
- 他との違い: 「安くておすすめ10選」の寄せ集めではなく、**実際に試した人の本音と、損しないための線引き**を書く。

## 2. 書き手（キャラ）

匿名でも「誰が書いているか」は見える方が読まれる。実在の個人情報は出さず、キャラとして立てる。

- 名前（仮）: **ポケ田**（変更可）
- 設定: 物価高で家計を見直し中の会社員。「我慢の節約は続かない」が持論。
- 口調: 友達に話す温度。です・ます基調に、ときどき本音のひとこと（「正直、これは微妙でした」）。
- やらないこと: 実在の住所・勤務先・家族構成など身元に繋がる話。

## 3. 何で稼ぐか（収益の柱）

| 柱 | 仕組み | 開始の目安 | 備考 |
|---|---|---|---|
| アフィリエイト（物販） | Amazon・楽天の商品リンク経由で売れたら報酬 | 記事10本＋独自ドメイン後 | もしもアフィリエイト等のASP経由で登録。ASPには本名・口座の登録が必要（公開はされない） |
| アフィリエイト（サービス） | ポイ活アプリ・家計簿アプリ等の登録で報酬 | 記事20本前後 | 単価は高めだが、記事の信頼が要る |
| ディスプレイ広告 | Google AdSense | 独自ドメイン＋記事20〜30本 | github.io のままでは審査が不確実。独自ドメインが前提 |

**正直な見通し:** 検索から人が来るまで数か月かかるのが普通。「寝ながら」に近づくのは、記事が溜まり、検索とSNSから自然に人が来るようになってから。最初の3か月は「仕組みと記事の貯金期間」と割り切る。

## 4. 守るべきルール（収益化に直結）

- **PR表記:** アフィリエイトリンクがある記事は、冒頭に「この記事にはPR（広告）を含みます」と書く。2023年10月からのステマ規制への対応と、ASPのルール順守のため。
- **体験の捏造をしない:** 買っていない物を「使ってみた」と書かない。信頼を失うと全部終わる。
- **AIの量産をしない:** 下書きにAIは使うが、体験・感想・事実確認は人が入れる。Googleのスパム規定（価値のない大量生成）を避ける。
- **匿名の徹底:** 公開物は `pocketlog-note` 名義。本名・個人メールは出さない。ドメインを取るときはWHOIS情報公開代行を使う。
- **税金:** 収益が出たら、副業所得の申告要否を確認する（会社員は年20万円が目安とされるが、住民税は別。具体的には税務署か税理士に確認）。

## 5. ステップ（フェーズとタスク）

### フェーズ1: 見せられる形にする（〜1週間）
- [ ] 方針と品質基準を決める（このメモ＋[[article-guide]]） ← いまここ
- [ ] サイトの見た目を作り直す（ロゴ文字・配色・記事カード・スマホ最適化）
- [ ] 必須ページを作る: 運営者情報（キャラ紹介）、プライバシーポリシー、お問い合わせ（匿名フォーム）
- [ ] 記事3本を新基準で書く（うち最低1本は実体験記事）
- [ ] GitHub Pages で公開

### フェーズ2: 人が来る土台を作る（〜1か月）
- [ ] 独自ドメインを取る（年1,000〜2,000円程度。要：あなたの購入判断）
- [ ] Google Search Console に登録、サイトマップを出す
- [ ] 記事を10本まで増やす（週2〜3本）
- [ ] X（旧Twitter）の匿名アカウントで記事を紹介（任意）
- [ ] OGP画像（SNSで記事を共有したとき出る画像）を自動生成する

### フェーズ3: 稼ぐ仕組みを入れる（1〜3か月）
- [ ] ASP（もしもアフィリエイト等）に登録 → Amazon・楽天と提携
- [ ] 記事テンプレートにPR表記・商品リンク枠を入れる
- [ ] 記事20〜30本で AdSense 申請
- [ ] 月1回、アクセスと収益を振り返り、伸びた記事の続編を書く

### フェーズ4: 寝ながらに近づける（3か月〜）
- [ ] ネタ出し→下書き生成を自動化（人は体験メモと最終チェックだけ）
- [ ] GitHub Actions で予約公開（決めた日時に自動で公開）
- [ ] 人気記事の定期更新（価格・在庫の確認）をリマインド

## 6. 追う数字（KPI）
